# Match Revisited: master list of classic matches

Working list for the weekly Match Revisited feature (one long-form write-up of a classic Liverpool match, published every Monday). This file is for planning only: the site never reads it. Published pieces live in `content/match-revisited/[slug].md`.

Add one entry per match under "Entries", copying the block below. No entry is written or published without Denny's approval.

## Fields

- **date**: the day the match was played (YYYY-MM-DD).
- **opponent**: the opposing club.
- **score**: Liverpool's score first (for example 4-3), whether home or away.
- **competition**: league, cup or European competition, and round if useful.
- **reason**: one line on why the match is on the list.
- **era**: the decade, such as 1980s (the piece's `decade` field).
- **status**: `unused` (not yet started), `written` (drafted, not yet live) or `published`.
- **needs-approval**: `yes` if Denny must approve this match by name before anything is written (for example anything touching Heysel or Hillsborough); otherwise `no`. When `yes`, do not write until Denny has approved in writing.

## Entry template

```
- date: YYYY-MM-DD
  opponent:
  score:
  competition:
  reason:
  era:
  status: unused
  needs-approval: no
```
